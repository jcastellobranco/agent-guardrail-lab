# ADR 0009 — Signed pull-only policy synchronization

The tenant-scoped sync agent pulls over HTTPS, validates Ed25519 bytes, checks scope and monotonic versions, compiles rules, then atomically renames a local file. The guardrail verifies again and swaps an immutable snapshot. Bundle freshness is based on issuedAt, not process restart. The Postgres bundle counter advances on each issuance; policy versions advance only on mutation. This avoids clock-only rollback checks and inbound connectivity to customer networks. A protected persistent volume is part of the trust boundary; a compromised host can roll back its disk. Probe artifacts follow the same pull-and-verify path (ADR 0014). Key rotation is future work.
